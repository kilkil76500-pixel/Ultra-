Configuration requise
---------------------
Variable d'environnement obligatoire :
  TELEGRAM_BOT_TOKEN   : token créé avec @BotFather sur Telegram

Déploiement local
-----------------
  pip install -r requirements.txt
  python -m playwright install chromium
  export TELEGRAM_BOT_TOKEN=<ton_token>
  ./start.sh

Déploiement avec fichier .env
------------------------------
  cp .env.example .env
  # Renseigner TELEGRAM_BOT_TOKEN dans .env
  ./start.sh          # charge .env automatiquement

Déploiement Docker
------------------
  docker build -t football-intelligence .
  docker run --env-file .env \
    -v "$PWD/cache:/app/cache" \
    football-intelligence

  ⚠️  Monter cache/ sur un volume persistant pour conserver les pronostics,
      résultats, calibrations, mémoire des équipes et exports.

Déploiement Heroku / Railway / Render
--------------------------------------
  Le Procfile démarre ./start.sh.
  Injecter TELEGRAM_BOT_TOKEN dans les variables d'environnement de la plateforme.

Vérification de l'archive
--------------------------
  unzip -t football-intelligence-v20.10-fusion-portable.zip
  cd football-intelligence-v20.10-fusion-portable/
